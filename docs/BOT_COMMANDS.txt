Project paths

SSH into the VPS
----------------

Restart the bot
---------------
cd /opt/trading-bot/BTC_Algo
sudo systemctl restart btc-fvg-bot.service

# Check it came back up
sleep 5
curl http://127.0.0.1:5557/health


Check bot status
----------------
sudo systemctl status btc-fvg-bot.service --no-pager


Watch live logs
---------------
cd /opt/trading-bot/BTC_Algo
tail -f logs/fvg_paper_bot.log

# Or via systemd journal
sudo journalctl -u btc-fvg-bot.service -f

# Last 50 lines
sudo journalctl -u btc-fvg-bot.service -n 50 --no-pager


Health check
------------
curl http://127.0.0.1:5557/health


Stop / start the bot
--------------------
sudo systemctl stop btc-fvg-bot.service
sudo systemctl start btc-fvg-bot.service

# Disable auto-start on boot
sudo systemctl disable btc-fvg-bot.service

# Enable auto-start on boot
sudo systemctl enable btc-fvg-bot.service

Environment variables (.env)
----------------------------

nano /opt/trading-bot/BTC_Algo/.env

# Important variables
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
HEARTBEAT_INTERVAL_SECONDS=300          # 5 minutes
TELEGRAM_MESSAGE_TTL_SECONDS=86400      # auto-delete after 24h

After editing .env, restart the bot:
sudo systemctl restart btc-fvg-bot.service


Common troubleshooting
----------------------
# Bot keeps crashing — check last error
sudo journalctl -u btc-fvg-bot.service -n 100 --no-pager

# Port 5557 not reachable — wait 10s after restart, then:
ss -tlnp | grep 5557

# Telegram not arriving but heartbeat works
# Usually VPS-to-Telegram network flakiness. Already retried 5 times.
# If persistent, increase HEARTBEAT_INTERVAL_SECONDS to reduce frequency.

# No-setup reasons not arriving
# Confirm code is present: grep notify_no_setup src/fvg/bot.py
# Confirm bot is processing 15-minute bars in logs/fvg_paper_bot.log
