================================================================================
1. FVG MOMENTUM BOT  (forward test / paper trading)
================================================================================

WHAT IT DOES
------------
It looks for short-term momentum bursts on the 15-minute BTCUSDT chart.
When it sees a strong directional move, it waits for a small pullback gap
(called a Fair Value Gap or FVG) and tries to enter in the direction of the
momentum. It then rides the move with a tight stop and take-profit plan.

WHICH FILES RUN IT
------------------
- src/fvg/strategy.py     -> finds setups and grades them
- src/fvg/bot.py          -> watches for new setups and sends orders to Bybit
- src/shared/config.py    -> settings (qty, stop %, TP %, API mode, etc.)
- src/shared/bybit_client.py -> order execution wrapper around Bybit API
- src/shared/store.py     -> records signals and fills to a local SQLite DB

HOW TO START IT
---------------
Double-click:  scripts\start_fvg_bot.bat
This runs only the momentum bot (no dashboard).

Or use:         scripts\run_fvg_forward_test.bat
Or use:         scripts\run_all.bat

TIME FRAMES
-----------
- Main signal chart : M15 (15-minute candles)
- Confirmation chart: H1  (1-hour candles for EMA/POC check)
- Bot checks        : every time a new M15 candle closes

ENTRY RULES (all must be true)
------------------------------
1. A "momentum leg" must exist:
   - At least 2 candles in a row moving in the same direction
   - Each candle's body must be >= 52% of its full range
   - The last candle must break above/below a recent swing point

2. After the leg, an FVG must form within the next 24 M15 candles:
   - Bullish FVG: high of candle (i-2) < low of candle (i)
   - Bearish FVG: low of candle (i-2) > high of candle (i)

3. Entry price = the MIDPOINT of that FVG gap.

4. Higher-timeframe confluence (H1):
   - Entry price must be within 0.3% of one of these levels:
     * EMA-20
     * EMA-50
     * 30-period Point of Control (POC) / volume node

5. Session filter:
   - Only trade during Asia, London, London-NY overlap, or New York windows.
   - The bot skips setups that form outside these sessions.

6. Grade:
   - Grade A+ : body ratio >= 70% AND HTF aligned
   - Grade A  : body ratio >= 52% AND HTF aligned

EXIT RULES
----------
- Hard stop-loss: 0.4% below/above entry (tight stop)
- TP1: 0.4% in profit. When TP1 hits, half position is closed.
- After TP1, a manual trailing stop is started for the remaining "runner".
- Runner hard TP: max 2% for Grade A, max 4% for Grade A+.
- If stop-loss is hit before TP1, the whole position is closed.

RISK / POSITION SIZING
----------------------
- Default start capital for the bot is set in config.py.
- Quantity per trade is fixed in config.py (for example, 2 contracts of BTC).
- No martingale. No pyramiding. One signal = one trade.

WHY THE BOT SOMETIMES SITS IDLE
--------------------------------
If you see no trades, it is usually because one of the entry rules above
was not met. Common reasons:

[ ] No momentum leg formed on M15.
[ ] A leg formed, but no FVG appeared within the next 24 candles.
[ ] FVG formed, but the midpoint is too far from H1 EMA-20/EMA-50/POC.
[ ] The setup formed outside the allowed trading session.
[ ] The candle body ratio was below 52%.
[ ] The bot only acts on the latest closed M15 candle. Older setups are
    ignored even if they still look good on the chart.
[ ] The bot was not running when the candle closed.
[ ] API/demo mode is set to read-only, or keys are missing.

The strategy is deliberately selective. In choppy or slow markets there
can be long gaps with no trades. That is by design.

================================================================================
2. QUICK "WHY NO TRADES?" CHECKLIST
================================================================================

1. Is scripts\start_fvg_bot.bat running?
2. Is the .env file filled with valid Bybit API keys?
3. Is config.py set to DEMO mode if you want paper trades?
4. Did a new M15 candle close while the bot was running?
5. Did the last closed candle pass all the rules above?
6. Check the logs/ folder for the latest bot log. It prints why each setup
   was accepted or rejected.
